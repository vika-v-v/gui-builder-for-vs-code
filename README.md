<h1>GUI Builder for Java Swing and Java FX</h1>

<p>This repository features only the documentation and images for the "GUI Builder" extension. GUI Builder is a minimalistic GUI Builder extension for VS Code made to boost your UI development ⏱️. Just drag and drop your UI elements and get a working app in minutes ✨. </p>

![Demo](https://raw.githubusercontent.com/vika-v-v/gui-builder-for-vs-code/basic/demo.gif)

<h1>Get Started 🧭</h1>
<ol style="list-style-type: decimal; padding-left: 1.5em;">
  <li><strong>Open GUI Builder</strong>: Press F1 and select `Open GUI Builder` from the options.</li>
  <li><strong>Create your Application</strong>: Click on the leftmost icon to open the palette and drag the elements from the palette to the field.</li>
  <li><strong>Generate Code</strong>: Click on the icon with `</>` at the bottom, select your framework, and click the <em>Generate code</em> button to convert your design into Java code.</li>
</ol>

![Screenshot](https://i.postimg.cc/QtDfphCG/screenshot-1.png)

# Features 🔧

<ul style="list-style-type: '→ ';">
  <li><strong>Code Generation</strong>: Creates Java code from the elements you drag and drop.</li>
  <li><strong>Themes</strong>: Choose from three beautiful themes to enhance your design experience:
    <ul style="list-style-type: '  → ';">
      <li>Modern light theme</li>
      <li>Modern dark theme</li>
      <li>Colorful theme</li>
    </ul>
  </li>
  <li><strong>Frameworks</strong>: Choose from two Java frameworks to generate your code:
    <ul style="list-style-type: '  → ';">
      <li>Java Swing</li>
      <li>Java FX</li>
    </ul>
  </li>
</ul>

More frameworks and programming languages are coming up soon!

<ul style="list-style-type: '→ ';">
  <li>[Coming up soon] <strong>Two-way code generation</strong>: Not only generate your code but also visualize the apps you already have in the GUI Builder!</li>
  <li>[Coming up soon] <strong>Layout elements</strong>: Better align your visual elements with layout presets.</li>
  <li>[Coming up soon] <strong>Theme Builder</strong>: Create your own theme with no line of code or select one from already defined.</li>
</ul>
